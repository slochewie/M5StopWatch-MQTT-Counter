## Notes

The launcher screenshot is a PNG because it is intended to look closer to the actual StopWatch launcher display and mechanical tally-counter icon.

Most other screenshots are SVG documentation mockups based on the current LVGL layout and firmware behavior. They are intended for README clarity, not pixel-perfect device captures.

When adding real device captures, prefer PNG or JPEG filenames that clearly distinguish them from conceptual mockups.
